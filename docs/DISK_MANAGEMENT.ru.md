# 🧹 Управление Дисковым Пространством

Этот модуль помогает администратору VPS управлять ограниченным дисковым пространством.

## 📊 Анализ (Disk Analyzer)

Агент сканирует следующие директории, которые занимают больше всего места:

1.  **Rust Build Artifacts (`target/`)**:
    *   **Описание**: Временные файлы компиляции Rust.
    *   **Размер**: Может достигать 5-10 GB.
    *   **Безопасность удаления**: Безопасно. При следующем обновлении (`cargo build`) они будут созданы заново (но сборка займет больше времени).

2.  **Docker Data**:
    *   **Описание**: Неиспользуемые образы, контейнеры, кэш сборки.
    *   **Размер**: Накапливается со временем.
    *   **Безопасность удаления**: `docker system prune -a` удаляет всё, что не используется *запущенными* контейнерами.

3.  **Logs (`journalctl`)**:
    *   **Описание**: Системные логи.
    *   **Безопасность**: Команда очистки оставляет примерно последние 24 часа логов.

## 🗑️ Очистка (Cleaning)

Доступны следующие команды через UI:

### 1. `Deep Clean (Build artifacts)`
*   **Команда**: `cargo clean` + `rm -rf frontend/node_modules`.
*   **Эффект**: Освобождает ~5-8 GB.
*   **Последствие**: Следующая кнопка "Update Agent" будет выполняться дольше (скачивание зависимостей + полная компиляция).

### 2. `Docker Prune`
*   **Команда**: `docker system prune -af`.
*   **Эффект**: Удаляет старые версии образов.

### 3. `System Logs`
*   **Команда**: `journalctl --vacuum-time=1d`.
*   **Эффект**: Оставляет логи только за последние 24 часа.
